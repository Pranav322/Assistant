Welcome to the Demo Page

This page simulates a customer site with the Contextly chatbot embedded. Fill in the config above and hit Load Widget — the chat button will appear in the bottom-right corner.

The demo will:

  • Call POST /api/v1/tokens/widget with your API key to get a JWT
  • Inject embed.js from the widget URL's origin
  • Open the chat widget pre-authenticated

How to get your credentials

1. Go to contextly.live (or localhost:3000) → create a project and index some documents.
2. In the project settings, create an API key.
3. Copy the project UUID from the URL: /projects/your-uuid
4. Paste both above and click Load Widget.
